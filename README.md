# Ольха — сайт кафе (демо)

Презентационный одностраничный сайт вымышленного кафе в Москве. HTML, CSS и чистый JavaScript, без сборки и зависимостей.

**Демо:** https://rotaxxx123soft-stack.github.io/olkha-cafe/

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 5510
```

## Структура

```
index.html          разметка: шапка, первый экран, меню, о кафе, контакты
css/style.css       стили, переменные палитры, адаптив
js/menu-data.js     данные меню (категории, блюда, цены в рублях)
js/main.js          вкладки меню, мобильная навигация, статус «открыто», анимации
assets/img/         фотографии (hero, menu, about), favicon
```

Чтобы изменить меню, правьте только `js/menu-data.js` — карточки и вкладки строятся автоматически.

Все данные (адрес, почта, блюда) вымышлены. Фотографии — [Unsplash](https://unsplash.com).
